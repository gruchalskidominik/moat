How this works

A friend uses Moat to block distracting apps. When they want to unlock, disable a wall, or turn guardian mode off, they need the 6-digit code shown here.

Read it to them only if you think they should have it. Codes change every 30 seconds. Keep this link private — anyone who has it can generate codes.

Nothing is sent anywhere. The code is computed in your browser from the link itself.
